QUICK START

从打开网页到进入游戏

  1. 使用电脑的新版 Chrome 或 Edge 打开本页。
  2. 选择「高级战争」或「高级战争 2」，点击「选择本地 .gba 文件」。不要选择压缩包。
  3. 想直接玩：点击「开始单人游戏」，画面出现后按 Enter，在菜单中按 Z 确认。
  4. 想联机：全员先选择相同的对局人数（2、3 或 4）和字节完全相同的游戏文件。玩家 1 创建房间并分享 8 位房间码，其余玩家依次输入房间码加入。人数必须到齐。
  5. 等状态显示「联机游戏中」后，全员在原版游戏内进入对应人数的 Multi-Pak 流程，分别操作自己的军队。房间连接成功与游戏同步完成分别显示。
  6. 结束时点击「结束」，在「你的存档」导出备份。断线将结束会话，不能原地恢复。

联机期间请保持页面在前台。切换标签页可能造成定时暂停并结束联机。没有合法 ROM 时仍可检查服务，但不能开始商业游戏。
