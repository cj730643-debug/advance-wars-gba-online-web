## 2–4-player extension · 2026-10-20
Inspected `src/gba/sio/lockstep.c`, its MAX_GBAS=4 coordinator and serialized driver topology; `src/gba/replicated-pair.c`, `src/gba/replica.c`, `src/gba/sio/netplay/input-sync.c`, `protocol-v2.c`, `session-v2.c`, libretro Netpacket header/callbacks, and the CC0 link diagnostic source. Underlying serial coordinator supports four IDs; replicated-pair, snapshot owner validation, pair input rings and v2 session protocol assume exactly two. Raising room capacity alone is insufficient.

Added `native/group/group-replica.*`, `replicated-group.*`, `group-input-sync.*` under MPL-2.0, derived from the pinned source and retaining notices. This separate namespace supports owner IDs 0–3 and active player count 2–4. Existing pair files, Netpacket protocol and tests are retained. `group-host.*` exposes snapshot/restore, per-owner inputs, cooperative frame scheduling, complete-state digests and verified local battery commits to the Worker. The only additional vendor modification is guarded `mLibretroAWGroupCore()` in `src/platform/libretro/libretro.c`, a private getter used by this adapter; original CPU/serial timing logic is unchanged. `native/core-host.cpp` and CMake expose new group calls alongside legacy calls.

`src/group-transport.mjs`, `group-session.mjs`, Worker/UI and Relay `/v2/rooms` implement authenticated multicast, a fixed full roster, bounded snapshot chunks, per-sender sequences, eight-frame input delay, and unanimous state barriers at frame 0 then every 60 frames. Netpacket remains pair-only; the separate host adapter owns group transport. Relay does not parse emulated state. Original `/v1/rooms` remains two-player. Each logical machine has independent temporary savedata on every client. At a successful barrier, only the local role's savedata is copied into the export buffer. This avoids changing serialized savedata metadata depending on which role is displayed.

Actual Emscripten build and 3-/4-client tests passed with self-authored CC0 diagnostics. No commercial ROM, BIOS or game resource was obtained. Original two-player fixture and tests remain. The new diagnostics verify active/unused receive registers, all four baud rates, role IDs, independent keys, state consensus, and distinct battery markers. Actual game compatibility remains unverified. Reproducible build commands are in README; extracted complete vendor source includes the guarded getter and original portability fixes.
